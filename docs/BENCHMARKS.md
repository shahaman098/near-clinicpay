# Benchmarks

Generated by `cd contract && cargo run --example bench -- 3.12` on 2026-11-14.

Local NEAR sandbox, one 5-unit invoice per operation. Gas is `total_gas_burnt` for the transaction plus every receipt outcome; cost is gas × the node's gas price. Mainnet's minimum gas price is 1e8 yocto/gas (protocol config), so USD figures here are a floor, not a quote.

- Gas price used: **100000000 yocto/gas**
- NEAR/USD: **3.12**
- Mainnet minimum: **1e8 yocto/gas**

## Method

- Each operation runs on its own invoice so state differences do not leak between rows.
- `total_gas_burnt` includes the transaction and all receipts; relayed rows are read from `tx` for the relayer's transaction hash.
- Storage is the contract account's `storage_usage` delta around one `create_invoice` (2 shares and 1 line included).
- The relayer rows use `relayer/payer.mjs` and `relayer/relayer.mjs` exactly as the sandbox tests do.
- The contract's token balance is asserted to be zero at the end.
